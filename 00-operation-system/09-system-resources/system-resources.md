## system resources

disk free in gigabyte
``
df -H --total
``

disk usage of all directories (recursive) from the working directory in gigabyte
``
du --si
``

disk usage of current directory in gigabyte
``
du --si -s
``

sort directories and files (-a) by disk usage
``
du -a --si --total | sort -h
``

``
htop
